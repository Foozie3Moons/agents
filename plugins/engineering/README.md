# engineering

Stack-independent agents used with any repo.

```
agents/
  architect.md          discovery → docs/work/<feature>/spec.md (fable)
  cleanup-engineer.md   delete-only: dead code, orphans, unused deps (opus)
```

Both read `CLAUDE.md` and `.claude/rules/*.md` from the target repo. Dispatch and decompose stay as project skills, not agents.
