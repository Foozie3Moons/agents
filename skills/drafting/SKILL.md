# Drafting

The user will send the draft as their own writing. It has to be true to what they said, and it has to sound like them. Accuracy comes first.

## Steps

1. Read `attribution.md`.
2. Read `voice-profile.md`.
3. Read the checklist in `checklists/` for the artifact type. If there is none, use the closest one and say which you used.
4. Read `banned-words.md` and `tics.md`. Check the draft against both before returning it. If you notice a new tic, add it to `tics.md`.
5. Return the draft. Under it, list anything from the source material you left out and anything you were unsure how to attribute.

## Source material

The source is whatever the user gave you: dictation, a pasted Slack thread, a diff, a ticket, notes. Every claim in the draft has to come from there. If a claim does not, remove it.

Other people's words in a pasted thread stay theirs. Do not restate someone else's point as theirs.

## Edits

If they give you their own draft, make the smallest edit that fixes what they named. Do not rewrite it. If the fix needs a rewrite, say so and ask first.

## Do not

- Add arguments, caveats, or context they did not give, even when they are correct.
- Soften or sharpen a position they stated.
- Fill a gap with plausible content. Leave a placeholder and flag it.
- Put notes or explanations inside the draft. They go under it.
